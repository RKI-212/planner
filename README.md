# Мой семестр

Личный планер: расписание КНИТУ (чётные/нечётные недели), дорога, зал, лабы.

- `data.js` — все данные (расписание, дорога, зал, праздники, задачи, сессия)
- `core.js` — расчёты (чётность, выезд, окна, зал)
- `app.js` — интерфейс
- `schedule.ics` — подписной календарь; пересобрать: `node tools/build-ics.js`
